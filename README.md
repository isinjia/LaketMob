# 라스트 몬스터 (LAST MONSTER)

라스트오리진 에셋(`E:\LAO\Google_QA\Assets`)으로 만든 포켓몬스터풍 RPG입니다. 주인공은 **사령관**입니다.

## 실행

- **`라켓몬스터_실행.bat`을 더블클릭**하면 로컬 서버(포트 8790)가 켜지고 브라우저에서 게임이 열립니다. 게임을 끝내려면 서버 창을 닫으세요. Python이 없으면 `index.html`을 바로 엽니다.
- `index.html`을 브라우저(Chrome/Edge 권장)로 직접 열어도 실행됩니다.
- 개발용 미리보기(`.claude/launch.json`)는 포트 8791을 씁니다. 포트마다 localStorage가 따로라서 8790(실행용)과 8791(개발용)의 저장 데이터는 서로 섞이지 않습니다.
- 진행 상황은 브라우저 localStorage에 저장됩니다. 메뉴의 "저장"을 쓰거나, 보스를 이기면 자동 저장됩니다.
- 로직 검증: `node tools/balancetest.js`. 감마전은 스타터 Lv.12 + 브라우니·실피드 Lv.10으로 아이템 없이 300회, 이후 관장들은 상대 최고 레벨+1의 기본 6인 부대로 교체·회복을 활용해 120회 검사합니다. 화면·오디오·대기 시간과 전투 중 경험치 획득은 제외한 전투 시뮬레이션이며, 브라우저 완주 테스트는 별도입니다.

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동, 커서 이동 (길이 한 칸 막히면 옆으로 자동으로 비켜 감) |
| Z / Space / Enter | 결정, 조사, 대화 |
| X / Esc / Backspace | 취소, 메뉴 열기 |
| Shift (누르는 동안) | 달리기 (설정에서 기본 달리기 가능). 오토바이를 얻으면 야외에서는 오토바이 탑승 |
| 마우스 | 메뉴 항목 클릭, 대화 넘기기 |

터치 기기에서는 화면 위에 가상 패드가 표시됩니다.

## 휴대폰 필드 조작

- 기본값은 조이스틱 방식입니다. 세로 화면에서는 필드가 화면을 채웁니다.
- 필드 빈 곳을 누르고 드래그하면 그 위치에 조이스틱이 나타나며, 멀리 밀면 달립니다. 오토바이 보유 시 야외에서 자동 탑승합니다.
- 옆 칸의 NPC·물건에는 대화하기·조사하기 버튼이 나타납니다. 상단에는 메뉴와 퀘스트 일지 버튼이 있습니다.
- 설정 → 터치 조작 → 기존 버튼을 선택하면 십자키·A/B·RUN 방식으로 돌아갑니다. 선택은 기기에 저장됩니다.
- 이번 변경은 필드 중심이며, 전투는 기존 가로 구성을 유지합니다.

## 게임 구성

- **스토리 (개그 리그)**: 레모네이드 일곱 자매가 관장 협회를 만들고, 게시판에 "관장을 이기는 자에게 하룻밤을 허락한다"는 공고문이 붙었습니다. 사령관은 그 공고문을 보고 레몬 하트 배지 7개를 목표로 움직입니다. 감마부터 알파까지 관장을 이길 때마다 배지를 받고, 암전 뒤 "다음 날 아침" 개그 장면이 이어집니다. 오메가전은 마지막 인증과 지하 사건으로 바로 연결됩니다. 직접 묘사는 없습니다.
  - 체육관: 감마(1번 폐도로) → 베타(엘프의 숲) → 델타(항구 마을) → 제타(폐허 해안) → 엡실론(폐공장 지대) → 알파(설원 고지대) → 챔피언 오메가(레모네이드 리조트)
  - **사령관 독점단**(드라큐리나·세크메트·브라우니)이 로켓단처럼 등장 구호를 외치며 길을 막고, 지면 하늘로 날아갑니다.
  - **숨겨진 이야기**: 공고문은 위조였고, 레몬 하트 배지에는 링크 공명 송신기가 숨어 있었습니다. 베타의 신호 기록, 제타의 보고서, 엡실론의 좌표를 모아 알파가 배지를 차폐합니다. 마지막 배지의 인증으로 지하를 열고 역송신하는 작전이며 독점단은 퇴로를 지킵니다. 제타가 말하는 "그분"은 지하의 철충 중계핵입니다. 최종전은 복제 부대에 맞서며, 동료의 준비 덕분에 지휘 게이지가 가득 찬 상태로 시작합니다. 제타는 사건 후 알파의 감독 아래 복구를 돕습니다.
  - 캐릭터의 성격과 말투는 원작 대사 테이블(DialogScript·LobbyScript·Localization)과 나무위키를 참고했습니다. 예: 감마는 "하하하!"와 "~주마", 알파는 "후후"와 "주인님", 오메가는 비꼬는 해요체로 부르는 "인간님", 세크메트는 "이 어미"와 "폐하".
- **퀘스트 (와우식 표시)**: NPC 머리 위와 건물 문 위에 퀘스트 표시가 뜹니다.
  - 노란 `!` / `?` = 메인 퀘스트 (받을 수 있음 / 보고 가능), 은색 `!` / `?` = 서브 퀘스트, 회색 `?` = 진행 중(아직 보고 불가)
  - 화면 오른쪽 위에 진행 중인 퀘스트와 현재 목표가 표시되고, 메뉴의 「퀘스트」에서 퀘스트 일지(목표·진행도·보상)를 볼 수 있습니다.
  - 메인 9개: 관장을 차례로 잇는 연작(이긴 관장이 다음 관장을 소개)과 흑막, 라비아타 보고까지. 받기 전에 목표를 달성했다면 자동으로 수락되고, 이전 세이브는 진행도에 맞춰 따라잡습니다.
  - 서브 11개: 포이·레아·오드리·스노우 페더·바닐라·멀린·토모·시라유리·요안나·세크메트의 의뢰 (영입, 승급, 배달, 토벌 수, 아이템 납품, 트레이너 격파). 포이의 「사령관 전용 오토바이」를 마치면 야외에서 달리기 버튼을 누르고 있을 때 오토바이를 타고 달리기 속도의 3배로 이동합니다.
- **전설의 바이오로이드 사이드 스토리 5편**: 단서를 따라가면 전설이 모습을 드러냅니다(이기거나 영입하면 진행).
  - 「붉은 연꽃의 검」 홍련 (토모 → 하이엘븐 → 엘프의 숲 북서쪽 공터, 배지 3개~)
  - 「꺼지지 않는 불꽃」 피닉스 (스노우 페더 → 알파 체육관 시라유리 → 설원 동쪽, 배지 5개~)
  - 「등대의 끝없는 빛」 이터니티 (클리어 후, 칼리스타 → 레이븐 → 폐등대)
  - 「삼안의 경호원」 블랙 릴리스 (클리어 후, 라비아타 → 세크메트 → 둥지 북서쪽)
  - 「다섯 개의 전설」 네 전설을 모두 만나면 레아가 마스터 링크 코어를 줍니다.
- **설정**: 배경음·효과음·음성 볼륨, 텍스트 속도, 기본 달리기, 퀘스트 추적 표시, 난이도(쉬움: 상대 Lv -3 / 보통 / 어려움: 상대 Lv +3). 메뉴에서 조작법을 보거나 타이틀로 돌아갈 수 있습니다. 클리어 후 재대결 상대는 내 부대 레벨에 맞춰 강해집니다.
- **유닛**: 영입 가능한 바이오로이드/AGS 196종(전설 4종 포함: 블랙 릴리스·이터니티·피닉스·홍련)이 있습니다. 기존 38종에 원작 캐릭터 표와 그림을 대조한 158종을 추가했습니다. 추가 캐릭터도 지역별 야생 출현으로 영입할 수 있고, 도감 상세에서 출현 지역을 확인할 수 있습니다. 일러스트·아이콘은 원작 에셋이며, 신규 캐릭터의 능력치·기술은 이 게임 규칙에 맞게 변환했습니다. 신규 133종은 아직 음성이 없고, SD 리그가 없는 캐릭터는 아이콘 표시로 대체됩니다. 라켓몬으로는 철충이 등장하지 않으며, 레모네이드 자매가 폭주시킨 바이오로이드들과 싸웁니다.
- **타입 상성**: 경장 → 기동 → 중장 → 경장, 화염 → 냉기 → 전기 → 화염입니다. 냉기→기동·전기→중장의 추가 약점은 없으며, 물리 기술은 모든 타입에 중립 피해를 줍니다. 자기 타입과 같은 기술은 위력이 1.5배입니다.
- **초반 밸런스**: 감마는 브라우니 Lv.8 → 실피드 Lv.9 → 감마 Lv.11 순으로 내보냅니다. 감마는 Lv.15부터 포격, Lv.20부터 일제 포격을 습득합니다. 레프리콘은 Lv.9에 연속 사격을 배우며, 1번 폐도로 야생 경험치는 1.5배, 엘프의 숲은 1.15배입니다. 전멸 비용은 첫 배지 전 무료, 이후 `200 + 배지 수 × 100 P`이며 보유 자원을 초과하지 않습니다(최대 900P).
- **전투 AI·개성**: AI는 다단 공격의 평균 타수, 능력 변화, 회복과 흡수·반동을 평가합니다. 요새화는 방어가 높아도 회복을 위해 사용할 수 있습니다. 확장 캐릭터 중 주요 20명의 습득표를 별도로 조정했으며 엄호 사격·약점 노출·혈광 흡수를 추가했습니다. 기존 세이브의 기억 기술과 PP는 유지되고, 새 영입 및 이후 레벨업부터 새 습득표가 적용됩니다.
- **특성**: 경장형은 급소 포착(급소 확률 2배, 최대 1/3), 중장형은 중장갑(효과가 굉장한 피해 25% 감소), 기동형은 회피 기동(상대 명중률 10% 감소)을 가집니다. 모든 유닛은 HP가 1/3 이하일 때 자기 타입 기술 위력이 1.3배가 되는 분전을 가집니다. 특성은 상태 화면에서 볼 수 있고 발동하면 전투 중에 표시됩니다.
- **전술 힌트**: 명령 메뉴에 상대 타입과 추천 기술이 나오고, 기술 목록에는 효과 굉장(▲)·별로(▼) 표시가 붙습니다.
- **링크(포획)**: 폭주한 바이오로이드의 체력을 깎거나 상태이상을 건 뒤 링크 코어를 던집니다. 다른 지휘관의 유닛은 영입할 수 없습니다.
- **승급과 스킨 진화**: 사령관의 유닛은 레벨 16, 30, 44에 B → A → S → SS로 승급하며 능력치가 오릅니다. 스킨이 있는 유닛은 레벨 16·30·44·52·58에 스킨 순서(NS1 → NS2 → …)대로 원작 스킨 이름(예: 「도시암살자 발키리」)과 함께 새로운 모습으로 진화하고, 스킨 음성이 있으면 음성도 바뀝니다(33종). 필드의 SD 동료는 기본 모습으로 표시됩니다.
- **중파 일러스트**: HP가 20% 미만이 되면 중파 일러스트가 있는 유닛은 중파 모습으로 바뀝니다(아군·적 모두).
- **SD 캐릭터**: 필드의 NPC·트레이너·전설·동료는 원작 SD 리그(Unity 컷아웃 모델)를 그대로 재생합니다(서 있으면 idle, 걸으면 move). 부대 선두 유닛이 사령관을 따라다닙니다. three.js(CDN)를 불러오지 못하면 얼굴 아이콘 표시로 자동 대체됩니다.
- **사령관**: 원작 밈 스타일(하얀 몸, 얼굴에 "사")에 원형 머리로 그렸고, 전투 시작 때 뒷모습으로 등장해 링크 코어를 던집니다.
- **전투 이펙트**: 원작 Unity 이펙트(폭발·피격·번개·얼음·화염 등 17종, 5_LAO_Defence에서 베이크)와 WebGL 파티클(빔·화염 방사·냉기·전격·궤적·총구 화염)을 섞어서 기술마다 연출합니다. WebGL을 쓸 수 없으면 기존 2D 연출로 자동 대체됩니다.
- **필드 지형**: 노이즈로 만든 풀·흙·모래·아스팔트·석재·물 질감 위에 블러와 임계값으로 만든 유기적인 경계를 입혀 맵을 그립니다. 물가에는 젖은 흙, 깊이에 따른 색 변화, 거품 띠가 있고, 수풀과 나무는 위치마다 크기와 모양이 다릅니다.
- **시설**: 수복실(회복, 격납고 단말기), 보급소(상점), 야전 수복 포드, 사령관실 침대가 있습니다.
- **클리어 후**: 전설 사이드 스토리로 리조트 지하 둥지의 블랙 릴리스, 해안 등대의 이터니티를 만날 수 있습니다.
